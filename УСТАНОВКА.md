# Установка бота учёта расходов

Инструкция рассчитана на то, что вы делаете это первый раз. Всё, что нужно —
браузер и телефон с телеграмом. Программировать не придётся: код готов, его
нужно только скопировать и настроить.

Времени займёт примерно 30–40 минут.

**Порядок важен.** Шаги идут так, что каждый следующий опирается на результат
предыдущего. Если что-то не получилось — не идите дальше, посмотрите раздел
«Если что-то не работает» в конце.

---

| Что | Где взять | Платно? |
|---|---|---|
| Google-аккаунт | у вас уже есть | бесплатно |
| Телеграм | у вас уже есть | бесплатно |
| Ключ Gemini API | Google AI Studio | бесплатный уровень |

Всё решение живёт внутри бесплатных лимитов. Подробнее — в конце, раздел
«Про лимиты».

## Шаг 1. Создать таблицу

1. Откройте [sheets.new](https://sheets.new) — создастся пустая Google-таблица.
2. Назовите её, например, «Семейный бюджет».
3. Посмотрите на адрес в браузере. Он выглядит так:

   `https://docs.google.com/spreadsheets/d/`**`1AbCdEf...XyZ`**`/edit`

   Выделенная часть между `/d/` и `/edit` — **идентификатор таблицы**.
   Скопируйте его в блокнот, он понадобится на шаге 5.

---

## Шаг 2. Создать проект со скриптом

1. В открытой таблице: меню **Расширения → Apps Script**.
2. Откроется редактор кода в новой вкладке. Назовите проект вверху слева,
   например «Бот расходов».
3. Слева в редакторе — список файлов. Там уже есть файл `Код.gs` (или `Code.gs`).

Теперь нужно перенести туда код бота.

### Как переносить

Весь код собран в один файл — создавать дюжину не нужно.

1. Откройте на компьютере файл **`dist/Код.gs`** из этого проекта (подойдёт
   любой текстовый редактор, хоть «Блокнот»).
2. Выделите всё (Ctrl+A) и скопируйте (Ctrl+C).
3. В редакторе Apps Script щёлкните внутри файла `Код.gs`, выделите всё, что
   там есть (Ctrl+A), и вставьте скопированное (Ctrl+V) — старое содержимое
   должно полностью замениться.
4. Сохраните (Ctrl+S).

Файл длинный, около 3800 строк, — это нормально. Ошибок и подчёркиваний в
редакторе быть не должно.

### Файл настроек проекта

1. Слева нажмите шестерёнку **Настройки проекта**.
2. Включите галочку **«Показывать файл манифеста appsscript.json в редакторе»**.
3. Вернитесь в редактор (иконка `<>`), откройте появившийся файл
   `appsscript.json` и замените его содержимое на содержимое файла
   **`dist/appsscript.json`** из этого проекта.
4. Сохраните.

Здесь задаётся часовой пояс (Иерусалим) и права доступа скрипта — без этого
даты будут считаться неверно.

> **Если предпочитаете разбивку по файлам** (так удобнее что-то править
> потом): вместо `dist/Код.gs` перенесите файлы из папки `src`,
> создавая каждый через **+** → **Скрипт** и вводя имя без расширения
> (`00_Config`, `01_Sheets`, …). Результат тот же — Apps Script всё равно
> склеивает их при запуске.
>
> **Если дружите с командной строкой** — так удобнее всего:
> `npm i -g @google/clasp`, `clasp login`. Затем скопируйте два образца
> настроек и впишите в них свои идентификаторы:
>
> ```bash
> cp .clasp.json.example .clasp.json      # идентификатор скрипта — из адреса редактора
> cp .deploy.json.example .deploy.json    # идентификатор развёртывания — clasp deployments
> ```
>
> Дальше всё делает `node tools/deploy.js`: прогоняет проверки, заливает код,
> создаёт версию, обновляет развёртывание и сохраняет копию проекта в ваш
> репозиторий. Копировать код вручную не нужно вообще.
>
> Эти два файла в репозиторий не попадают: у каждой установки они свои.

## Шаг 3. Создать бота в телеграме

1. Найдите в телеграме [@BotFather](https://t.me/BotFather) и напишите ему `/start`.
2. Отправьте команду `/newbot`.
3. BotFather спросит **имя бота**. Это подпись, которую видите вы в списке
   чатов, — делайте её понятной: «Семейный бюджет».
4. Потом спросит **логин бота** — уникальный адрес, заканчивающийся на `bot`.
   А вот его, наоборот, стоит сделать бессмысленным: `qx7m2vk_bot`,
   `t3rf9zab_bot`. Логин — главный способ, которым бота находят посторонние,
   и по бессмысленному его не найдут. Имя и логин между собой не связаны:
   в списке чатов вы увидите «Семейный бюджет», логин будет виден только в
   адресе.
5. В ответ BotFather пришлёт **токен** — длинную строку вида
   `7123456789:AAF...`.

   **Этот токен — пароль от бота.** Никому его не показывайте и не выкладывайте
   в интернет. Скопируйте в блокнот.

### Заодно спрячьте бота получше

Прямо в чате с BotFather, той же командой-меню:

- **Описание оставьте пустым.** Не пишите «бот для учёта семейных расходов» —
  по описанию тоже ищут. Если BotFather просит описание, пропустите шаг или
  поставьте точку.
- **`/setjoingroups`** → выберите своего бота → **Disable** — бота нельзя будет
  затащить в чужой групповой чат.

  > Пропустите этот пункт, если хотите получать месячный отчёт в общий семейный
  > чат: чтобы бот туда писал, его надо в этот чат добавить. Тогда просто не
  > запрещайте группы — добавить бота всё равно сможет только тот, кто знает
  > его логин.

Само по себе это уже почти исключает случайную находку. Плюс к этому бот
никому, кроме вас двоих, не отвечает вообще — снаружи он выглядит неживым.
Как это устроено — в шаге 8.

## Шаг 4. Получить ключ Gemini

Ключ нужен, чтобы бот понимал голосовые сообщения и читал чеки. Без него бот
тоже работает, но только с текстом.

1. Откройте [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Войдите под тем же Google-аккаунтом, где лежит таблица.
3. Нажмите **Create API key** (Создать ключ API).
4. Придумайте имя ключа — любое, например «Family Budget».
5. В поле **Choose an imported project** ключ просит указать проект Google Cloud.
   Если там написано **No Cloud Projects Available** — проектов у вас ещё нет,
   это нормально. Раскройте список и выберите **Create project**:
   - название проекта — любое, например `family-budget`;
   - организацию, если спросят, оставьте **No organization**;
   - проект создастся за несколько секунд и сам подставится в поле.

   Пункт **Import project** нужен только тем, у кого проекты уже есть.
6. Нажмите **Create key** и скопируйте ключ (строка вида `AIza...`) в блокнот.

Карту привязывать не нужно: и создание проекта, и бесплатный уровень Gemini
работают без биллинга. В списке ключей в столбце **Billing Tier** будет
написано `Free` — это подтверждение, что вы на бесплатном уровне.

## Шаг 5. Прописать секреты в скрипт

Токен и ключи не хранятся в коде — они лежат отдельно, в защищённых свойствах
проекта.

1. Вернитесь в редактор Apps Script.
2. Слева — шестерёнка **Настройки проекта**.
3. Прокрутите вниз до раздела **Свойства скрипта** → **Добавить свойство**.
4. Добавьте три свойства (для каждого — «Добавить свойство» заново):

| Имя свойства | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather из шага 3 |
| `GEMINI_API_KEY` | ключ из шага 4 |
| `SPREADSHEET_ID` | идентификатор таблицы из шага 1 |

5. Нажмите **Сохранить свойства скрипта**.

Имена свойств пишутся ровно так, как в таблице выше — заглавными буквами,
с подчёркиваниями.

## Шаг 6. Создать листы в таблице

Речь про редактор Apps Script — вкладку, которая открылась на шаге 2
(«Расширения → Apps Script»), а не про саму таблицу.

1. Над кодом в этой вкладке есть панель с кнопками: «Сохранить» (дискета),
   «Выполнить» (Run), «Отладка» (Debug), а сразу за ними — **выпадающий список
   функций**. Раскройте его и выберите **`setupSpreadsheet`**.

   > Список пуст или нужной функции нет? Сохраните файл (Ctrl+S): имена функций
   > подтягиваются только из сохранённого кода.

2. Нажмите **Выполнить**. Результат появится внизу, в панели «Журнал
   выполнения» (Execution log).

Тем же способом запускаются все остальные функции из этой инструкции —
`setWebhook`, `setBotCommands`, `createMonthlyTrigger`, `selfCheck`. Кнопок в
интерфейсе у них нет, только этот список.
3. Google попросит разрешения. Это нормально — скрипт ваш собственный:
   - **Разрешить доступ** → выберите свой аккаунт;
   - появится предупреждение «Google не проверил это приложение» — нажмите
     **Дополнительные настройки** → **Перейти к проекту «Бот расходов»
     (небезопасно)**;
   - **Разрешить**.
4. Внизу появится журнал выполнения со строкой «Готово. Таблица: …».

Откройте таблицу — внизу окна появились пять **листов** (это ярлычки-вкладки в
нижней части таблицы, рядом друг с другом):

- **Расходы** — сюда бот пишет записи;
- **Доходы** — пустой, задел на будущее;
- **Категории** — справочник, уже заполнен под жизнь в Израиле;
- **Настройки** — параметры, которые вы правите руками;
- **Лог** — ошибки и всё, что бот не смог разобрать.

## Шаг 7. Научить бота получать сообщения

Здесь есть развилка, и о ней стоит знать заранее.

**Напрямую телеграм со скриптом разговаривать не может.** Обычно ботам ставят
«вебхук»: телеграм сам стучится по адресу и приносит сообщение. С Apps Script
это не работает — на любой запрос он отвечает перенаправлением на другой адрес.
Браузер за таким перенаправлением идёт, а телеграм нет: он считает это ошибкой
и складывает сообщения в очередь. Настройками не лечится, проверено.

Поэтому два пути. Оба рабочие, переключаться между ними можно в любой момент
одной функцией.

### Путь А — опрос (проще, ничего лишнего)

Скрипт сам раз в минуту спрашивает телеграм, нет ли новых сообщений.

Выполните функцию **`switchToPolling`** (файл `11_Polling`) — и всё.

- Ответ приходит **в течение минуты**.
- Никаких сторонних сервисов, ничего настраивать.
- Съедает около трети суточной квоты Apps Script — запас остаётся.
- Сообщения не теряются: телеграм хранит недоставленное сутки.

### Путь Б — вебхук через посредника (мгновенно)

Между телеграмом и скриптом ставится крошечная программа на бесплатном хостинге
(Vercel). Она принимает сообщение, проверяет подпись и передаёт дальше, спокойно
проходя то самое перенаправление.

- Ответ приходит **мгновенно**.
- Нужен аккаунт на Vercel и разовая настройка.
- В системе появляется четвёртый сервис, через который проходят сообщения:
  суммы, описания, фотографии чеков. Он ничего не хранит, но технически видит.

Как настраивается (это уже сделано, здесь — на случай переустановки):

1. Развернуть скрипт как веб-приложение: **Начать развёртывание → Новое
   развёртывание** → шестерёнка → **Веб-приложение**; запуск от имени **Я**,
   доступ **Все**. Скопировать адрес `/exec`.
2. В папке `proxy` этого проекта выполнить `vercel deploy --prod`, получить
   адрес посредника вида `https://…vercel.app/api/telegram`.
3. Прописать в переменных проекта на Vercel:
   - `APPS_SCRIPT_URL` — адрес `/exec` из пункта 1;
   - `WEBHOOK_SECRET` — любое случайное слово.
4. Прописать в свойствах скрипта:
   - `WEBHOOK_URL` — адрес посредника;
   - `WEBHOOK_SECRET` — то же слово, что и на Vercel.
5. Выполнить функцию **`switchToWebhook`**.

Секретное слово нужно, чтобы на адрес посредника не прошёл чужой запрос:
телеграм подписывает им каждое обращение, посредник проверяет подпись.

### И в том, и в другом случае

Выполните функцию **`setBotCommands`** — в телеграме у бота появится меню
команд.

Проверить, что всё сошлось, можно функцией `selfCheck`: она пишет, в каком
режиме работает приём сообщений.

## Шаг 8. Пустить себя и жену

Пока бот не знает, кто «свой», и не отвечает никому — вообще. Если сейчас ему
написать, он промолчит. Так и задумано: для постороннего бот выглядит неживым.

Но каждую попытку он записывает в таблицу — оттуда и возьмём нужные номера.

1. Откройте своего бота в телеграме (BotFather дал ссылку вида `t.me/ваш_бот`),
   нажмите «Старт» и напишите ему что угодно, например `привет`. Ответа не
   будет — это правильно.
2. Попросите жену сделать то же самое со своего телефона.
3. Переключитесь на вкладку браузера с **таблицей** (не с Apps Script) и внизу
   окна щёлкните ярлычок листа **Лог**. В нём появились строки «Сообщение от
   постороннего», а в правом столбце — что-то вроде:

   ```
   {"userId":123456789,"chatId":123456789,"username":"anatoly","name":"Анатолий","text":"привет"}
   ```

   Число после `userId` — это и есть телеграм-айди. Найдите свою строку (по
   имени) и строку жены, выпишите оба числа.
4. Перейдите на лист **Настройки**.
5. В строке **«Разрешённые телеграм-айди»** впишите оба числа через запятую:
   `123456789, 987654321`.
6. В строке **«Чат месячного отчёта»** впишите, кому присылать отчёт первого
   числа. Проще всего — те же два числа через запятую, что и строкой выше:

   ```
   123456789, 987654321
   ```

   Тогда первого числа каждый получит свой экземпляр отчёта в личку от бота.
   В личной переписке номер человека и номер чата совпадают, поэтому отдельно
   ничего искать не нужно.

   Оставите одно число — отчёт будет приходить только этому человеку.

   > **Хотите отчёт в общий чат, а не в личку каждому?** Создайте группу с женой,
   > добавьте туда бота, напишите в группе `/whoami` — бот покажет айди чата
   > (у групп он отрицательный, вида `-1001234567890`). Впишите это число вместо
   > двух личных. Поменять можно когда угодно, это одна ячейка.

7. Напишите боту `50 хлеб` — он должен ответить «✅ Записал: 50 ₪», а в таблице
   появится строка. Заработало — значит, список заполнен верно.

   Если бот по-прежнему молчит, значит, ваш айди в списке с ошибкой: проверьте,
   что числа разделены запятой, без лишних пробелов внутри числа и без кавычек.

Строки в листе «Лог» после настройки можно удалить — они больше не нужны.

## Шаг 9. Дать доступ к таблице второму пользователю

1. Откройте таблицу → синяя кнопка **Настройки доступа** (Share) справа вверху.
2. Введите адрес Gmail жены.
3. В выпадающем списке выберите **Редактор**.
4. **Отправить**.

Теперь таблица видна обоим. Бот при этом работает от вашего имени — это
нормально, записи от обоих попадут в одну таблицу, а в столбце «Автор» будет
видно, кто записал.

## Шаг 10. Включить месячный отчёт

В редакторе выберите функцию **`createMonthlyTrigger`** → **Выполнить**.

Первого числа каждого месяца около 10 утра бот сам пришлёт в указанный чат отчёт
за прошедший месяц: сколько потратили всего, по категориям с долями, насколько
это больше или меньше прошлого месяца, пять самых крупных трат и кто сколько
записал.

Проверить, как отчёт выглядит, можно в любой момент командой `/otchet`.

---

## Шаг 11. Проверить, что всё на месте

Выберите функцию **`selfCheck`** → **Выполнить**. В журнале выполнения появится
список: что настроено, чего не хватает.

Идеальный результат:

```
=== Проверка настройки ===
✅ Проблем не найдено
ℹ️ Сведения:
  • Таблица: Семейный бюджет
  • Разрешённых пользователей: 2
  • Категорий в справочнике: 12
  • Базовая валюта: ILS
  • Бот: @nash_budget_2026_bot
  • Вебхук: https://script.google.com/macros/s/.../exec
  • Gemini отвечает, тестовая категория: Продукты
```

Готово. Дальше — как этим пользоваться.

## Как пользоваться

**Текстом** — сумма и описание в свободной форме:

```
360 шек отправка машины
45 продукты
вчера 1200 гараж
12.05 200 руб такси
$45 подписка нетфликс
```

Валюта по умолчанию — шекель. Дату можно не писать (поставится сегодняшняя), а
можно сказать «вчера», «позавчера», «12.05» или «12 мая».

**Несколько трат одним сообщением.** Так тоже можно:

```
250 продукты, 80 бензин и 45 аптека
```

Бот запишет три отдельные строки и ответит одной сводкой:

```
✅ Записал 3 траты, всего 375 ₪

1. 250 ₪ · Продукты — продукты
2.  80 ₪ · Транспорт и автомобиль — бензин
3.  45 ₪ · Здоровье и аптека — аптека
```

Под ней — кнопки с номерами: «✏️ 2» правит категорию второй траты, «🗑 2»
удаляет её, остальные не трогая.

Дата, названная в начале, относится ко всем тратам сообщения: «вчера 250
продукты и 80 бензин» — обе записи лягут вчерашним днём.

**Если суммы не хватает — не записывается ничего.** Ни одной строки, даже если
часть трат понятна. Бот покажет, что разобрал, пометит пропуск и спросит:

```
Разобрал 2 траты:
1. 250 ₪ — продукты
2. сумма? — бензин

Пока не знаю все суммы, не записываю ничего.
Сколько потратили на «бензин»?
```

Ответили числом — записались обе. Если пропусков несколько, бот спросит про
каждый по очереди и запишет всё разом, когда выяснит последний.

Передумали на середине — напишите `/otmena` или просто начните новую запись:
если в ответе будет не только число, но и описание («120 такси»), бот поймёт,
что это уже другая трата, и старый черновик отбросит.

**Голосом** — просто наговорите: «двести тридцать шекелей супермаркет». Понимает
русский, иврит и смешанную речь, до минуты длиной. В ответе покажет, что
расслышал, — так сразу видно, если понял неверно. Несколько трат подряд голосом
тоже можно: «сто двадцать такси и двести на продукты».

**Фотографией чека** — пришлите снимок. Сумму возьмёт из строки итога (а не
сложит позиции), дату — с чека, распознает магазин и позиции. Чеки на иврите
читает. Если чек смазан или итог не виден — покажет, что смог разобрать, и
попросит подтвердить или прислать сумму числом. **Без подтверждения запись не
создаётся.**

Подпись к фото бот считает уточнением: напишете под чеком «ужин с друзьями» —
это станет описанием и повлияет на категорию.

**Ссылкой на чек** — магазины всё чаще присылают SMS вида «получен новый чек,
для просмотра нажмите здесь» со ссылкой. Перешлите такую SMS боту целиком:
ссылку он откроет сам.

Для крупных сетей — Carrefour, Mega, «Йейнот Битан», «Битан маркет», «Рами
Леви», IKEA — бот берёт чек готовыми данными, а не распознаёт: сумма, дата и
позиции получаются точными, вплоть до скидок по акциям. Для остальных ссылок
читает, что найдёт: PDF и картинку разбирает как фотографию чека, обычную
страницу — как текст.

Служебные ссылки в той же SMS (политика приватности, сайт сети, соцсети) бот
пропускает и по ним не ходит.

Если ссылка не открылась — скажет об этом. Когда сумма видна в самом тексте
SMS, предложит записать её кнопкой; если суммы нет, попросит прислать скриншот
или написать сумму. Молча и наугад ничего не записывает.

Приписка по-русски рядом со ссылкой («это на работу») станет описанием
расхода — сам ивритский текст SMS в описание не идёт, он сохраняется в столбце
«Исходный текст».

**Доходы** — пишите сумму с плюсом: `+12000 зарплата`. Плюс — правило железное:
с ним запись всегда уходит в лист «Доходы», что бы ни было написано рядом.
Слова «зарплата», «аванс», «премия», «гонорар» бот узнаёт и без плюса, но тогда
проверьте ответ: в нём будет написано «Записал доход» и кнопка «Это расход» —
одно нажатие переносит запись обратно.

У доходов свой справочник категорий, отдельный лист «Категории доходов»:
зарплата, фриланс, подарки, проценты, продажа вещей, пособия. Правится так же
руками, как и расходный.

**Возврат денег** — «вернули 200 за чайник» — бот считает не доходом, а отменой
траты: запишет минусом в ту же категорию расходов. Так траты по категории
остаются честными: купили чайник за 200 и вернули — по «Дому и быту» выйдет 0,
а не «потратили 200 и заработали 200». Чеки на возврат из магазина
распознаются так же автоматически.

**Снятие наличных и переводы друг другу** бот не записывает вовсе и объясняет
почему: деньги не потрачены, а переложены из кармана в карман. Записывать надо
саму трату — когда эти наличные потратятся. Перевод постороннему человеку
(«перевёл Диме за ремонт») — обычный расход, его бот запишет.

**Сколько осталось** — команда `/dohody`: доходы за месяц по категориям, под
ними расходы и остаток. Та же строка появляется в `/mesyac` и в месячном отчёте,
как только в месяце есть хоть один доход.

**Обновления бота.** Раз в неделю бот сам проверяет, не вышла ли новая версия,
и если вышла — пишет, что изменилось, с кнопкой «Как обновиться». По нажатию
присылает файл с новым кодом и три шага: открыть редактор, выделить всё,
вставить. Полминуты. Записи, настройки и справочники останутся на месте,
а прежний код сохранится в истории версий Apps Script, откуда его можно
вернуть. Проверить самому — команда `/obnovit`, узнать свою версию —
`/versiya`.

Сообщение приходит одному человеку — тому, у кого есть доступ к редактору
кода. Обычно это тот, кто ставил бота. Кому именно писать, можно задать
в листе «Настройки», строка «Кто обновляет бота». Когда обновление встанет,
бот сам расскажет остальным, что появилось нового.

Если обновляться не хотите — просто не нажимайте кнопку: сам по себе бот
ничего не меняет.

**Кнопки под каждой записью** — «Изменить категорию» и «Удалить». Удаление
не стирает строку, а помечает её: в сводках и отчётах она не учитывается, но
история сохраняется.

**Команды:**

| Команда | Что делает |
|---|---|
| `/mesyac` | расходы за текущий месяц по категориям |
| `/poslednie` | последние 10 записей |
| `/segodnya` | сумма за сегодня |
| `/otchet` | полный отчёт за прошлый месяц |
| `/spravka` | справка по формату ввода |
| `/otmena` | отменить незавершённую запись |
| `/whoami` | показать свой телеграм-айди и айди текущего чата |

## Что можно менять без программиста

Всё это правится прямо в таблице, код трогать не нужно.

### Лист «Категории»

Три столбца: категория, подкатегория, ключевые слова через запятую.

Этот список решает две задачи. Во-первых, он передаётся модели как набор
допустимых категорий — чтобы она выбирала из ваших, а не выдумывала свои.
Во-вторых, по ключевым словам бот подбирает категорию сам, когда модель
недоступна.

- **Добавить свою категорию** — допишите строку внизу.
- **Научить бота слову** — допишите его в «Ключевые слова» нужной строки.
  Например, увидели, что «Шуфа» уходит не туда — добавьте `шуфа` в строку
  «Продукты / Супермаркет».
- Ключевые слова ищутся **по вхождению**, поэтому лучше писать корень слова:
  `продукт` поймает и «продукты», и «продуктов».
- Слишком короткие и общие слова лучше не добавлять: `газ` найдётся внутри
  «магазин».

### Лист «Настройки»

| Параметр | Зачем |
|---|---|
| Базовая валюта | в чём считается итог, по умолчанию ILS |
| Курс USD / EUR / RUB | сколько шекелей в единице валюты; правьте, когда курс уходит далеко |
| Разрешённые телеграм-айди | кто может писать боту |
| Чат месячного отчёта | кому приходит отчёт первого числа; несколько адресатов — через запятую |
| Модель для медиа / для текста | какую модель Gemini использовать |

Курсы применяются в момент записи: старые строки не пересчитываются — это
правильно, расход был по тогдашнему курсу.

### Лист «Лог»

Сюда попадает всё, что пошло не так: сбои модели, нечитаемые сообщения, попытки
чужих написать боту. Если бот «странно себя ведёт» — сначала загляните сюда.
Лист можно чистить: удаляйте старые строки, кроме шапки.

## Если что-то не работает

**Бот молчит на любые сообщения.**
Молчание — его штатная реакция на чужого, поэтому первым делом проверьте белый
список: лист «Настройки», строка «Разрешённые телеграм-айди». Числа должны быть
разделены запятой, без кавычек и без пробелов внутри самого числа. Свой айди
всегда можно подсмотреть в листе «Лог» — напишите боту что угодно и посмотрите
свежую строку «Сообщение от постороннего».

Если в списке всё верно, а бот всё равно молчит, выполните `selfCheck` в
редакторе. Скорее всего, не установлен вебхук — тогда выполните `setWebhook`.
Проверить можно функцией `getWebhookInfo`: в ответе должен быть ваш адрес и не
должно быть `last_error_message`.

**Бот перестал отвечать после того, как вы правили лист «Настройки».**
Проверьте, что не сдвинулись строки и названия параметров в первом столбце не
изменились: бот ищет их по точному названию. Если строку случайно удалили —
верните название и значение вручную, или выполните `setupSpreadsheet` заново
(существующие данные он не тронет, но и удалённую строку не восстановит —
проще вписать руками).

**Изменили код — бот работает по-старому.**
Apps Script отдаёт телеграму ту версию, которая опубликована. После правки кода:
**Начать развёртывание → Управление развёртываниями** → карандаш напротив
вашего развёртывания → **Версия: Новая версия** → **Развернуть**. Адрес при этом
не меняется, вебхук переустанавливать не нужно.

**Голосовые и чеки не разбираются, текст работает.**
Дело в Gemini. Проверьте `GEMINI_API_KEY` в свойствах скрипта и загляните в лист
«Лог»: там будет причина. Частая — исчерпан дневной бесплатный лимит; тогда
достаточно подождать до следующих суток.

**Чек прочитался, но сумма не та.**
Нажмите «Удалить» под записью и введите сумму текстом. Если ошибка повторяется
на чеках одного магазина — напишите об этом, промпт распознавания можно
подстроить (файл `03_Gemini.gs`, функция `geminiParseReceipt_`).

**Расход попал не в ту категорию.**
Нажмите «Изменить категорию» под записью — и заодно допишите ключевое слово в
лист «Категории», чтобы в следующий раз бот не ошибся.

**Бот записал один расход дважды.**
Такое возможно, если телеграм не дождался ответа и повторил доставку. Защита
есть, но если случилось — просто удалите лишнюю запись кнопкой.

## Про доступ и приватность

Кто и что может увидеть:

**Посторонний, случайно наткнувшийся на бота.** Ничего. Бот не отвечает никому,
кроме двух айди из белого списка: ни на сообщения, ни на команды, ни на нажатия
кнопок. Со стороны он выглядит неработающим. Попытка тихо записывается в лист
«Лог» — вы увидите, что кто-то приходил.

**Посторонний, узнавший логин бота.** То же самое. Знание логина даёт только
возможность открыть чат и написать в пустоту.

**Посторонний, узнавший адрес скрипта.** Тоже ничего, но этот случай можно
закрыть дополнительно. Добавьте в свойства скрипта свойство `WEBHOOK_SECRET`
с любым выдуманным словом (например, `kukuruza77`), после чего заново выполните
`setWebhook`. Тогда скрипт будет принимать только запросы с этим словом в
адресе, а всё прочее отбрасывать.

**Ваша таблица.** Видна только тем, кому вы дали доступ на шаге 9.

Чего скрыть нельзя: переписка с ботом идёт через серверы телеграма и видна им,
как любая переписка с ботами (это не секретный чат), а таблица физически лежит
у Google. От посторонних людей защита полная, от самих Telegram и Google — нет.

## Про лимиты

Всё решение бесплатно, но у бесплатного есть потолки. Для семьи из двух человек
они недостижимы с большим запасом:

| Сервис | Ограничение | Наш расход |
|---|---|---|
| Apps Script | 90 минут работы скрипта в сутки | секунды на сообщение |
| Apps Script | 20 000 внешних запросов в сутки | 2–4 на сообщение |
| Google Sheets | 10 млн ячеек в таблице | ~17 ячеек на запись |
| Telegram Bot API | без практических ограничений | — |
| Gemini (бесплатный уровень) | сотни запросов в сутки | 1 запрос на сообщение |

При 15–20 сообщениях в день это несколько процентов дневного лимита. Даже день
на 50 сообщений оставит кратный запас.

Точные числа Google периодически меняет — их видно на странице лимитов в
AI Studio. Есть ещё ограничение на минуту (примерно десяток запросов): оно
проявится, только если вы вдвоём одновременно вывалите десяток сообщений
подряд. На этот случай бот умеет подождать и повторить запрос.

**Если лимит всё-таки кончится, бот не сломается.** С текстом он справится сам,
своим разбором: поймёт сумму, дату, валюту и подберёт категорию по списку слов
из листа «Категории». Потеряется только разбор нескольких трат в одном
сообщении — в таком режиме бот запишет первую. Голос и чеки будут отвечать
«не разобрал», причина — в листе «Лог». На следующие сутки всё вернётся само.

### Про содержимое запросов

По условиям **бесплатного** уровня Gemini содержимое запросов может
использоваться Google для улучшения их моделей. Поскольку теперь через модель
проходят все сообщения, включая текстовые, туда попадают суммы, описания трат,
фотографии чеков и расшифровки голосовых.

Если однажды захотите это закрыть — на платном уровне такого использования нет,
а при вашем объёме он стоит порядка полудоллара в месяц. Переключение — это
привязка карты к тому же ключу, код менять не нужно.
