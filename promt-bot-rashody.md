# Промпт для Claude Code: телеграм-бот учёта семейных расходов на Google Apps Script

## Задача

Создать телеграм-бота на Google Apps Script, который принимает записи о расходах текстом, голосом и фотографиями чеков, разбирает их, категоризирует и складывает в одну Google-таблицу.

Пользователей двое — муж и жена. Устройства: iPhone, Android, два компьютера на Windows. Бот должен работать одинаково со всех. Все ответы бота — на русском языке.

Решение должно укладываться в бесплатные лимиты: Apps Script, Google Sheets, Telegram Bot API и бесплатный уровень Gemini API.

## Хранилище данных

Одна Google-таблица со следующими листами.

**Лист «Расходы»** — столбцы:
- дата и время создания записи;
- дата расхода;
- сумма;
- валюта;
- сумма в базовой валюте (шекель);
- категория;
- подкатегория;
- описание;
- магазин или заведение;
- позиции чека (одной строкой, если распознаны);
- автор записи (имя пользователя);
- способ ввода (текст / голос / фото);
- исходный текст сообщения или расшифровка;
- источник категории (словарь / модель / вручную);
- ссылка на файл в телеграме (для голосовых и чеков);
- признак удаления.

**Лист «Категории»** — справочник категорий и подкатегорий с ключевыми словами для сопоставления. Правится руками, без изменения кода. Заполнить стартовым набором, релевантным для семьи, живущей в Израиле: продукты, транспорт и автомобиль, жильё и коммунальные, здоровье и аптека, кафе и рестораны, дети, одежда, связь и подписки, развлечения, подарки, прочее.

**Лист «Настройки»** — базовая валюта (шекель), курсы валют по умолчанию, список разрешённых телеграм-айди, идентификатор чата для месячного отчёта.

**Лист «Лог»** — ошибки, необработанные сообщения, сырые ответы модели при сбоях разбора.

**Задел на будущее:** структура должна позволять добавить лист «Доходы» с той же логикой, не переписывая парсер и категоризатор.

## Ввод: текст

Пользователь пишет боту свободным текстом, например «360 шек отправка машины», «45 продукты», «вчера 1200 гараж».

Парсер вытаскивает сумму, валюту, дату и описание:
- валюта по умолчанию — шекель;
- распознавать шекель, рубль, доллар, евро в разных написаниях, включая «шек», «шекелей», «₪», «руб», «$», «долларов», «евро»;
- даты понимать словами: «вчера», «позавчера», конкретное число месяца, число с месяцем;
- если суммы в сообщении нет — бот задаёт уточняющий вопрос и строку не пишет.

## Ввод: голосовые сообщения

Бот принимает голосовые сообщения. Порядок работы:
1. Скачать файл через Telegram Bot API: сначала `getFile` по идентификатору файла, затем загрузка по полученному пути. Формат телеграма — OGG с кодеком Opus.
2. Передать аудио в Gemini API (модель Flash) в base64 с промптом, который просит **одновременно** расшифровать речь и вернуть строгий JSON: сумма, валюта, дата, описание, категория из переданного списка. То есть для голоса распознавание и разбор делаются одним запросом, без промежуточного текстового парсера.
3. В столбец исходного текста писать расшифровку, в способе ввода отметить «голос».
4. В подтверждении показать расшифровку, чтобы было видно, если бот расслышал неверно.

Речь может быть на русском, на иврите или смешанной — промпт к модели должен это учитывать.

Если аудио длиннее минуты или модель вернула невалидный JSON — бот отвечает, что не разобрал, и просит написать текстом.

## Ввод: фотографии чеков

Бот принимает изображения — и как фото, и как файл-документ с изображением. Телеграм при отправке фотографией отдаёт несколько размеров — брать самый большой. Скачивание — тем же способом: `getFile`, затем загрузка по пути.

Изображение передать в Gemini API (модель Flash) в base64 с промптом, который просит вернуть строгий JSON:
- итоговая сумма чека;
- валюта;
- дата и время покупки с чека;
- название магазина или заведения;
- категория из переданного списка;
- список позиций, если они читаются.

Правила распознавания:
- итоговую сумму брать именно из строки итога, а не складывать позиции самостоятельно;
- если отдельно видны чаевые или сервисный сбор — включать их в итог, но помечать в описании;
- чеки бывают на иврите, в том числе с суммами и датами в местном формате; также поддержать русские и английские чеки;
- дату брать с чека, а не дату отправки сообщения; если дата не читается — использовать текущую и пометить это в подтверждении.

Запись в таблицу: магазин — в соответствующий столбец, позиции — одной строкой в свой столбец, способ ввода — «фото», ссылка на файл сохраняется, чтобы можно было вернуться к оригиналу.

Если изображение нечитаемое или сумма не найдена — бот показывает, что смог разобрать, и просит подтвердить или ввести сумму вручную. **Запись без подтверждения не создаётся.**

Если к фото приложена подпись — использовать её как уточнение категории и описания поверх распознанного с чека.

## Категоризация

Два слоя:
1. **Словарь.** Поиск по ключевым словам из листа «Категории».
2. **Модель.** Если совпадения нет — вызов Gemini API (Flash или Flash-Lite) с промптом, который передаёт список существующих категорий и просит выбрать одну из них либо предложить новую. Ответ требовать строгим JSON.

Фолбэк: при ошибке, невалидном ответе или превышении лимита — писать категорию «Без категории», запись **не терять**, ошибку зафиксировать в листе «Лог».

Ключ Gemini API хранить в свойствах скрипта, не в коде.

## Взаимодействие с ботом

После записи бот отвечает короткой сводкой — сумма, категория, описание (плюс расшифровка для голоса, плюс магазин для чека) — и даёт инлайн-кнопки «Изменить категорию» и «Удалить».

Удаление помечает строку признаком удаления, а не стирает её физически. Все сводки и отчёты удалённые строки игнорируют.

Команды:
- расходы за текущий месяц по категориям;
- последние десять записей;
- сумма за сегодня;
- справка по формату ввода.

## Месячный отчёт

Триггер по времени в Apps Script: в первый день месяца бот сам присылает в общий чат отчёт за прошедший месяц — общая сумма, разбивка по категориям с долями, сравнение с предыдущим месяцем, топ-5 самых крупных трат, разбивка по авторам записей. Идентификатор чата брать из листа «Настройки».

## Техническая часть

- Веб-хук на функцию `doPost`, ответы через Telegram Bot API.
- Токен бота и ключ Gemini API — в свойствах скрипта (Script Properties).
- Защита от повторной обработки одного и того же апдейта по идентификатору обновления.
- Проверка телеграм-айди отправителя по белому списку из настроек; чужие сообщения игнорировать с записью в лог.
- Код разбить на отдельные файлы: парсер текста, работа с медиа (скачивание файлов), обращения к Gemini, категоризация, работа с таблицей, телеграм-слой, отчёты, настройки.
- Код с комментариями на русском.
